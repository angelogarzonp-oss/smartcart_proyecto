El proyecto

Problema

Saturación de aplicaciones web con frameworks pesados. Se requiere evaluar librerías reactivas ligeras para mejorar el rendimiento.

Estado del arte

Adopción industrial de librerías como Alpine.js y HTMX para desarrollo dinámico con bajo consumo de memoria.

Metodología

Diseño Front-End responsivo (HTML5/CSS3) e integración con API REST y base de datos relacional.

Esta página es la propia evaluación: el catálogo y los filtros se actualizan con HTMX (el servidor devuelve HTML), el carrito, los modales y el tema con Alpine.js, y todo se guarda en SQL a través de la API REST.

Conclusiones

Las librerías ligeras como Alpine.js y HTMX son una alternativa viable a los frameworks pesados: reducen los tiempos de carga y respuesta, y se integran con una arquitectura Cliente - Servidor - Base de Datos basada en Node.js/Express y SQL.
